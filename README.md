# maxVFX Beauty Engine v0.9.0 — Integrated Beta

WebGL2 + MediaPipe 기반 PC/모바일 뷰티 카메라. **현재 v0.9.0은 실험적 통합 베타**입니다. 사용자가 GitHub에 직접 업로드하도록 전체 소스를 제공하며, 이번 릴리스 작업에서 GitHub를 수정하지 않았습니다.

## v0.9.0 주요 추가

- **영역별 얼굴 커스터마이징:** 코·입술 볼륨·눈썹 높이·입꼬리·볼·턱 6개 슬라이더. 사진 전체 지원, 라이브에서 일부만 사용자 선택 시 약하게 적용(턱/볼 라이브 OFF).
- **안전한 UV 워프:** 얼굴 윤곽 외부와 주변 배경 항등 매핑, 변위 제한, 기존 메시 뒤집힘·늘어짐 방지, 불안정 추적 시 해제.
- **스튜디오 라이트 BETA:** 조명 방향·강도·웜/쿨 조정, 4종 빠른 프리셋. 실제 3D 광원의 물리 재구성은 아님.
- **My Look 저장/공유:** 얼굴 조절/조명 설정을 로컬에 최대 16개 저장, JSON 및 HTTPS 공유 링크, 이전 룩 파일 호환.
- **전후 비교 이미지:** 원본·보정 결과를 나란히 배치한 PNG 출력. 기존 PNG/모바일 공유 유지.
- **LIVE QA 진단:** FPS·해상도·포즈·메시 안전 상태 표시.

## 시작하기

`index.html`을 HTTPS 또는 로컬 HTTP 개발 서버에서 엽니다. GitHub Pages HTTPS가 모바일 카메라에 적합합니다. 처음 실행 시 샘플 인물이 표시됩니다. 카메라·사진 버튼으로 입력을 바꿀 수 있습니다. 얼굴 추적/의미론적 마스크는 최초 실행에서 MediaPipe 관련 CDN/모델 파일 다운로드가 필요합니다. **실기기 GPU 품질 QA는 아직 완료하지 않았습니다.**

**프리셋 공유는 사진/얼굴 랜드마크가 아닌 수치 설정만 공유**합니다. 원본 사진, 얼굴 좌표, Reference Match 대상 사진을 타인에게 자동 전달하지 않습니다.

# maxVFX Beauty Engine v0.3.1



## v0.3.0 — 포즈 연동 얼굴 음영과 가림 경계 안정화 (BETA)

이번 버전은 3D 모델을 복원하는 릴리스가 아니라 **얼굴 방향을 참고해 부드러운 명암을 표현하는 3D 곡면 근사**와 **머리카락/가림 영역 마스크의 시간적 안정화**를 구현한 단계입니다.

- **3D 포즈 연동 얼굴 음영 (선택형)**: 기존 MediaPipe 얼굴 방향 및 화면 환경광으로 얼굴 표면을 완만한 타원체로 근사하여 확산광의 명암을 약하게 변화시킵니다. 새 `3D 포즈 기반 부드러운 얼굴 음영` 스위치는 기본 OFF, `얼굴 방향 연동 조명`과 `자동 환경 조명`이 함께 ON일 때 활성화됩니다. 표정/포즈 신뢰도 낮음과 강한 회전 시 자동 감쇠하며 밝기 변화는 피부 영역에서만 한정합니다. **실제 광원의 위치/색을 3D로 재구성하는 기능은 아닙니다.**
- **Temporal Occlusion Matte**: 새 `semantic-temporal.v0.3.0.mjs`로 가림 영역 보호를 빠르게 적용하고 천천히 해제하는 2속도 필터를 추가했습니다. 머리카락·손으로 추정된 경계에 1픽셀 보호 여유를 주며, 얼굴이 움직이거나 새 이미지가 선택되면 이전 시간 필터를 리셋합니다.
- **움직임에 따른 마스크 정렬 검증**: 마지막 분할 당시 코 위치와 현재 추적 위치가 일정 거리 이상 벌어지면 이전 마스크를 사용하지 않습니다. 가림 보호의 잔상/틀어짐을 방지하지만 손가락의 정확한 추적은 아직 불가능합니다.
- **룩 프리셋 호환성**: `lighting.relight3D`를 옵션 필드로 추가했습니다. 이전 v0.2.x 룩 JSON은 정상 불러오고 새 기능은 OFF로 유지됩니다. 얼굴 이미지·랜더마크·3D 형상 데이터는 룩 JSON에 포함하지 않습니다.
- **기존 유지**: v0.2.9 머리카락 분할 선택형 BETA, Live Safe 턱·UV 보호, 2D Face Mesh·Reference Match, 모바일 고정 프리뷰, 환경 조명, PNG/룩 공유.
- **제약**: 얼굴을 완전히 가릴 때의 지속 추적, 측면에서 보이지 않는 얼굴의 정확한 재구성, 실제 3D 조명 반사·그림자, 개인별 3D 얼굴 스캔, 모바일 실기기 GPU 검증은 미구현/미검증입니다. **안전상 라이브 턱선 변형은 여전히 OFF**입니다.

### GitHub 직접 업로드
ZIP을 풀면 `index.html`, `main.v0.3.0.js`, `semantic-temporal.v0.3.0.mjs`, `face-light-field.v0.3.0.mjs`, `assets/`, `docs/`, `tests/`가 저장소 루트에 있습니다. **GitHub 저장소를 이 패치에서 수정하지 않았습니다.** 직접 전체 파일을 기존 저장소에 업로드하세요. GitHub Pages에서 `v0.3.0` 버전을 확인하고 실기기에서 검증한 후 공개 사용을 권장합니다.

## v0.2.9 — 픽셀 단위 의미론적 가림 보호 / 측면 안정화 (옵트인 BETA)

- **MediaPipe SelfieMulticlass ImageSegmenter**로 6개 픽셀 클래스를 인식합니다: 배경(0), 머리카락(1), 몸 피부(2), 얼굴 피부(3), 의류(4), 기타/액세서리(5). 이중 **얼굴 피부만 필터링 가능 영역**으로 취급하고, 나머지는 보정 후 원본 픽셀을 우선 합성합니다.
- 새 `semantic-occlusion.v0.2.9.mjs`는 클래스/품질 검사, 1px 경계 feather, GPU RGBA 마스크 변환, 950ms 라이브 마스크 유효기간과 소스 세대 번호 검사를 제공합니다.
- 새 `semantic-occlusion-runtime.v0.2.9.mjs`는 버튼을 켠 뒤에만 Google 모델+MediaPipe WASM을 다운로드합니다. **CPU delegate** 사용(일부 iOS Safari GPU 모델 결과 클래스 혼동 문제 회피). 카메라 긴 변 320px(배터리 256px)로 축소하고 420~820ms 간격으로 분할하여 저사양에서 과도한 중복 추론을 제한합니다. 동기 추론이므로 여전히 프레임 저하 가능성이 있습니다.
- WebGL2 `uSemanticMask`(TEXTURE3) 합성 시 **변형 전 픽셀 좌표**로 분할 결과를 샘플링해 손/머리카락/의상/배경 등의 픽셀이 기존 얼굴 메시 UV에 끌려가지 않도록 보호합니다. 마스크 오류·얼굴 미검출·시간 초과 시 자동 OFF / 기존 Live Safe로 복귀합니다.
- 손은 별도 hand detector로 추적하는 것이 아니라 **body-skin** 클래스의 일부로 추정합니다. 완전한 가림 추적·3D 복원·정확한 머리카락 투과광·실제 물리광 추적은 **미구현**입니다. 기본은 OFF이며 사용자가 명시적으로 켜야 합니다.
- 이전 피부·메이크업·Reference Match·My Look 저장/공유·고정 모바일 프리뷰·포즈·라이트 추정·메시 foldover/stretch 보호는 유지합니다. 사진/랜드마크/분할 결과는 메모리에만 보관하고 JSON 프리셋에는 저장하지 않습니다.
- **검증**: Node 순수 수학/가짜 MediaPipe 객체 기반 컨트롤러 회귀 + Python 정적 검사. 실기기 Android/iOS 카메라/모델 다운로드/GPU 시각화는 미검증입니다.

### 사용 방법
1. 전체 ZIP 압축 해제 후 `index.html`이 GitHub 저장소 루트에 위치하도록 파일 전체 업로드(옛 버전 소스는 유지).
2. GitHub Pages 화면에서 `v0.2.9`를 확인하고 카메라 또는 사진을 실행합니다.
3. 보정 패널의 **가림 영역 AI 보호 · BETA**를 켭니다. 첫 실행 시 인터넷 연결과 추가 모델 다운로드가 필요합니다.
4. 머리카락이 이마에 걸치거나 손이 볼을 가릴 때 비교 기능으로 확인합니다. 느리거나 분할이 불안정하면 해당 토글을 끄고 기본 라이브 안전 모드를 이용합니다.

## v0.2.8 — 부분 가림·측면 포즈·라이트 깜빡임 안전화 (BETA)

**이번 단계는 얼굴 가림의 의미론적 분할이 아니라, 랜드마크 이상값 검사/제한된 보간 및 안전한 페이드를 추가하는 단계입니다.** 손·머리카락·안경의 실제 픽셀 마스크 또는 완전히 가려진 얼굴의 3D 추론은 포함하지 않습니다.

- **부분 가림/랜드마크 이상값:** `occlusion-guard.v0.2.8.mjs`에서 9개 핵심 앵커의 움직임 중앙값으로 머리 전체 이동을 판단합니다. 소수(최대 23개)의 이상점만 이전 검증된 지점에서 짧게 보정하고, 다중 부위 이상·급격한 이동·240ms 초과 연속 복구는 거부합니다. 데이터는 메모리에서만 처리합니다.
- **필터 페이드:** `live-transition.v0.2.8.mjs`에서 실시간 FPS와 독립적인 시간 기반 가중치로 눈 변형·피부/메이크업 마스크·포즈 조명 강도를 완만하게 조절합니다. 추적 불명확 시 마지막 유효 상태를 최대 310ms 이내에서만 제한적으로 사용하며, 이후 원본으로 복귀합니다. **완전히 가려진 얼굴을 계속 추적하는 기능이 아닙니다.**
- **측면 포즈 안전:** `poseSafetyMultiplier()`가 Yaw/Pitch가 큰 경우 변형을 점차 감쇠합니다. 정면은 기존 보정 강도를 유지합니다. 라이브 턱 변형은 기존 v0.2.7과 동일하게 안전을 위해 비활성 상태입니다.
- **조명 변화 안정화:** `ambient-light.v0.2.8.mjs`에 수치별 변화율 한도를 가진 라이트 완충 필터를 추가합니다. 카메라 자동 노출/화이트밸런스가 순간적으로 튀어도 피부에 즉시 큰 색·조도 변화가 나타나지 않게 합니다. **실제 3D 광원 방향·그림자·반사는 계산하지 않습니다.**
- **UI/프리셋:** 상단 고정 프리뷰/하단 슬라이더/샘플 사진/룩 저장·공유/Reference Match 모두 유지합니다. 이상값 보호와 추적 재획득 상태를 프리뷰 아래에 표시합니다. 별도 설정 파일 스키마는 변경하지 않았습니다.
- **배포:** GitHub는 수정하지 않았습니다. ZIP을 풀면 루트에 `index.html`이 있으며 파일 전부를 저장소 루트에 업로드해야 합니다. Pages 배포 후 `v0.2.8` 표기를 확인하세요.

**검증 범위:** Node 순수 모듈/메시/환경 조명 회귀 테스트 및 Python 정적 검사. Android/iOS 실제 카메라 + GPU, 손·머리카락 가림, 측면 60도, 10분 FPS/발열, 실시간 색 품질은 **미검증**입니다. 실제 인물 외형이나 성형 수술 결과를 의학적으로 예측하지 않습니다.

## v0.2.7 — Face Pose + Pose-Aware Relighting 기반 패치

이번 버전은 **사진/카메라 얼굴 방향(회전) 추정**과 기존 환경 조명 보정의 연동을 추가한 **3D 포즈 기반 조명 시각화 기초(BETA)**입니다. 3D 재구성이나 실제 광원 위치 추적이 아닙니다.

- **3D 포즈 방향 추정:** MediaPipe Face Landmarker의 선택적 `facialTransformationMatrixes`를 활성화해 얼굴 yaw·pitch·roll을 추정합니다. 매트릭스가 없거나 신뢰하기 어렵다면 2D 랜드마크 기반의 보수적 대체 추정으로 전환합니다.
- **포즈 연동 환경 조명:** 기존 화면 밝기/색온도/좌우 광량 추정과 얼굴 방향을 결합한 아주 약한 로컬 셰이딩을 피부 마스크 영역 안에만 적용합니다. 하이라이트·머리카락·눈·입·배경을 보호하며, 조명 자동 OFF나 새 스위치 OFF로 포즈 효과를 끌 수 있습니다.
- **회전 안정화:** 시간 필터, 36° 이상 순간적인 포즈 변화 거부, 300ms 이상 오래된 포즈 폐기, 강한 회전 시 라이브 피부 보정량 감소를 추가합니다. 기존 Live Safe 턱선/UV 안전장치, 짧은 가림 유예 후 원본 복구는 유지합니다.
- **모바일 조작:** 기존 상단 고정 프리뷰 유지. 아래 제어 패널에서 얼굴 방향/신뢰도 확인과 `얼굴 방향 연동 조명` ON/OFF.
- **프리셋 호환:** My Look JSON에 `lighting.poseAware`를 옵션으로 추가해 저장/불러오기/공유합니다. 이전 v0.2.6 JSON은 자동으로 기본값(ON)을 사용하며 얼굴 사진이나 랜드마크를 포함하지 않습니다.
- **MediaPipe 호환:** GPU/CPU 각각 3D 행렬 ON을 시도하고 실패하면 OFF로 재시도해 기존 2D 추적이 죽지 않도록 구성했습니다.

> **이번 범위에서 구현하지 않은 것:** 실제 물리 기반 3D 라이트 추적, 완전한 측면·가려진 얼굴의 구조 복원, 머리카락/손/안경 세밀한 오클루전 세그먼테이션, 사용자별 3D 얼굴 형상 저장, 수술 후 실제 결과 예측. 라이브 카메라와 GPU 품질/지연/발열은 실기기 QA가 필요합니다.

### GitHub 직접 업로드

## 이번 업데이트 — Adaptive Live Performance

- **자동 라이브 화질:** 균형 모드(최대 768px / 목표 상한 30fps)부터 시작해 실제 지연이 장기간 반복될 때만 절전(640px / 24fps) → 배터리(512px / 20fps)로 점진 전환합니다. 안정되면 단계적으로 균형 모드까지 복귀합니다.
- **수동 설정:** 자동 / 고화질(960px) / 균형(768px) / 절전(640px) / 배터리(512px). 모바일에서도 상단 프리뷰를 그대로 보면서 아래 패널에서 선택 가능합니다.
- **텍스처 최적화:** 영상과 마스크의 크기가 같다면 `texSubImage2D()`를 사용하고, 정지 이미지는 동일한 소스에 대해 GPU 업로드를 반복하지 않습니다.
- **추적 비용 제어:** 라이브 모드에 따라 Face Landmarker 실행 주기(110–240ms)와 피부 마스크 갱신 주기(130–280ms)를 조절합니다. 큰 얼굴 움직임은 예외적으로 마스크 즉시 갱신.
- **안정성:** 탭 일시중지/복귀 시 라이브 얼굴 좌표 안전 재획득, 늦게 도착한 카메라 권한 요청 폐기, WebGL 컨텍스트 손실 시 2D 폴백 및 복원 시 GPU 재초기화.
- **기존 기능:** v0.2.4 Live Safe 턱선 변형 안전장치, 메쉬 UV stretch/foldover fallback, 샘플 인물, 피부·메이크업, 미형, Reference Match, 전후/3면 비교 유지.

| 라이브 모드 | 렌더 최대 긴 변 | 렌더 목표 FPS 상한 | 추적 최소 간격 | 마스크 최소 간격 |
|---|---:|---:|---:|---:|
| 고화질 | 960 px | 30 | 110 ms | 130 ms |
| 균형 | 768 px | 30 | 140 ms | 180 ms |
| 절전 | 640 px | 24 | 190 ms | 230 ms |
| 배터리 | 512 px | 20 | 240 ms | 280 ms |

이 값은 **설정 정책**입니다. 실제 FPS, 온도, 배터리 절약량을 측정한 결과가 아닙니다. 외부 라이브 영상으로 의료·성형 수술 후 모습을 예측하지 않습니다.

## 실행 제약·검증

- 첫 얼굴 추적 시 MediaPipe JS/WASM 및 모델을 CDN에서 다운로드하기 때문에 인터넷이 필요합니다. 얼굴 사진·비디오·좌표는 기본적으로 기기 내 메모리에서 처리되며, 프리셋에는 저장되지 않습니다.
- WebGL2 불가 시 Canvas2D 기본 색감·비교만 가능하며 정밀 얼굴형/Reference Match 변형은 제한됩니다.
- Node 동적 테스트 **22개**, Python 정적 회귀 **10개**, JavaScript 구문·자산 검사 통과.
- Chromium의 로컬 페이지 접근이 `ERR_BLOCKED_BY_ADMINISTRATOR`로 차단되어 **실제 브라우저 GPU 렌더링, 카메라 성능, 10분 발열/배터리 테스트는 실행하지 못했습니다.** 실기기 테스트 전 상용/라이브 운영에서 안정성을 보장할 수 없습니다.
- 모든 메이크업/참고 얼굴 변환은 시각화이며 실제 성형 시술/수술 결과를 예측하거나 보장하지 않습니다.

## v0.3.1 — 포즈 연속성·마스크 정렬·GPU 메시 업로드 최적화 (2026-11-04)
- **Pose Continuity**: 3개 이상 안정 프레임 확인 후 얼굴 변형을 서서히 복구. 급격한 회전·포즈 추정 누락 때 즉각 신뢰도 감쇠. 2D fallback은 낮은 확신도로 제한.
- **조명 신뢰도**: 포즈 신뢰도 감소 시 3D 근사 조명 신뢰도도 함께 감쇠. 실제 3D 복원·광원 위치 추적은 아님.
- **Matte Alignment**: 코뿐 아니라 양쪽 눈 중심·너비·기울기 확인. 옛 마스크가 회전한 얼굴의 잘못된 위치에 붙는 상황 억제.
- **GPU/CPU**: 메시 변형 강도가 0이고 이미 항등 UV가 업로드된 상태면 불필요한 4,161-정점 재계산/버퍼 업로드 생략. 변형 필요 시 즉시 갱신.
- **보안/개인정보**: 얼굴 데이터·사진 추가 저장 및 네트워크 전송 기능 없음. 프리셋 구조 및 사진 공유 기존 방식 유지.
- **중요**: 실제 모바일 GPU 장시간 출력·조명 화질·측면 가림·턱선 품질은 실기기 QA 필요. 자동 테스트는 이 효과를 입증하지 못함.
