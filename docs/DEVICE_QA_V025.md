# maxVFX Beauty Engine v0.2.5 — Android/iOS 현장 QA

실기기 검증 전까지 **프로덕션/라이브 무결성을 보장할 수 없습니다.** 아래 항목은 사용자가 GitHub Pages에 배포한 뒤 수행할 권장 체크리스트입니다.

## 실행 환경
- 브라우저: Android Chrome, Samsung Internet, iOS Safari, PC Chrome/Edge
- 인물 샘플(내장), 카메라 전면·후면, PNG/JPG 사진 업로드 사용
- 각 기기에서 10분 이상 라이브 구동; 기기 종류, 배터리 시작/종료 %, 밝기, 발열 정도, FPS 최소·평균·최대 기록

## 빠른 기능 회귀
- [ ] 페이지 상단 `v0.2.5` 표시, 브라우저 콘솔 치명 오류 없음
- [ ] 최초 샘플 사진 정상 표시, 원본/보정 수직 분할선 일치
- [ ] 좌/우 턱선에 찢김·떨림·배경 늘어짐 없음
- [ ] 피부/미형/메이크업/색감 슬라이더를 움직여도 프리뷰가 고정
- [ ] `라이브 품질` 자동/고화질/균형/절전/배터리 전환 시 검은 화면 없음
- [ ] **자동 모드:** 10분 라이브 구동 시 UI가 중단되지 않음; 현재 fps 및 프로파일 표시 갱신
- [ ] 카메라를 크게 움직이거나 얼굴을 잠시 가려도 깨진 메시 대신 정상 원본으로 복귀
- [ ] 얼굴이 재인식되면 피부/메이크업 마스크 정상 회복, 눈/턱 경계 일그러짐 없음
- [ ] 전면 ↔ 후면 전환 및 사진 업로드 ↔ 카메라 전환 시 프리즈/화면 충돌 없음
- [ ] 카메라 접근 허용 창이 열린 동안 사진 모드 전환 후 늦은 카메라가 자동 재실행되지 않음
- [ ] 앱을 백그라운드로 보냈다 돌아와도 사진 분석은 유지되고 라이브는 안전하게 재획득
- [ ] 사진 저장, 원본 비교, Reference Match 부위별 슬라이더·3면 비교 유지
