# v0.2.8 모바일 라이브 QA 체크리스트

**이 문서는 테스트 절차이며, 테스트 완료 보고가 아닙니다.**

| 단계 | 사용자 동작 | 기대 화면 | 관찰 항목 |
|---|---|---|---|
| A | 카메라 정면 30초 | 보정이 서서히 안정적으로 나타남 | 첫 진입 깜빡임/FPS |
| B | 좌우 15°→30°→45°→60° | 각도가 커질수록 변형 완화, 배경/턱선 찢어짐 없음 | 좌우 비대칭/마스크 경계 |
| C | 손으로 한쪽 눈 0.1~0.5초 가림 | 짧은 이상점 보정 또는 자연스러운 원본 복귀 | 눈/턱 위치 오염 |
| D | 코·입·볼을 차례로 가림 | 추적 오염 시 안전 게이트, 심한 경우 원본 | 눈썹/립·블러셔 이동 |
| E | 눈에 앞머리 걸침, 안경 장착/제거 | 분리된 랜드마크 변화로 전체 메시 깨짐 없음 | 주변 가장자리/눈 변형 |
| F | 얼굴 완전 가림 2초 후 복귀 | 무한 홀드 금지, 원본으로 복귀, 다시 부드럽게 적용 | 복귀 시간/메이크업 점프 |
| G | 실내 조명 ON/OFF, 카메라 자동 노출 변화 | 순간 라이트 깜빡임 제한, 지속 변화는 천천히 추종 | 명부 클리핑·피부색 |
| H | 어두운 방→밝은 방, 역광 | 얼굴 원본 질감 보존 | 톤 펌핑/색온도 |
| I | 전면/후면/사진/샘플 소스 전환 | 지난 얼굴 좌표가 새 소스에 적용되지 않음 | 유령 얼굴/잔상 |
| J | 10분 이상 카메라 구동 | 앱 정상 조작과 추적 재획득 가능 | CPU/GPU 메모리, fps, 발열 |

기준: 모양이 불명확하거나 310ms 이상 새 유효 얼굴 결과가 없다면 추적된 얼굴 Warp를 중단. 이 시간이 정확도/기기 성능을 보장하는 것은 아닙니다.

장기 목표: 별도 segmenter(손/머리카락), occlusion-aware 3D face, photoelectric exposure correction, 복구 후 스냅 최소화. 현재는 BETA이며 실기기 결과를 QA 리포트에 추가해야 함.
