### 테스트 입력 매트릭스
- 인물: 다양한 얼굴형/조명/피부톤/표정/안경/머리카락 가림(각 대상의 권리 및 사용 동의 확인).
- 참고 사진: 정면 / 3/4측면 / 표정 다름 / 낮은 해상도 / 다중 얼굴.
- 디바이스: 360×667, 390×844, 1280×800 화면, 실제 Android/iOS/Windows/macOS.
- 스냅샷: 마스크(눈·코·입술·볼·윤곽), 변형 이전/이후, 스트렝스 0/35/100, 저장 이미지.

### 초기 성능 목표(보장치 아님)
- v0.2.3 단계 모바일 720p 기준 30fps 추구; 실기기 GPU/온도/배터리 프로파일 필요.
- 얼굴 분석을 UI 메인 스레드에서 오래 점유하지 않도록 추론 업데이트 스케줄링.
- 레퍼런스 분석은 사용자가 파일을 바꿀 때만 실행하고, 재렌더은 파라미터 변화 시에만 수행.

### 현재 상태
- 문서와 설정 스키마 검사만 가능. **실제 Reference Match 런타임·임상 검증·모바일 QA는 아직 미수행.**
