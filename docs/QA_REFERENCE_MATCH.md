## v0.2.2 실제 구현과 QA 계획 구분
- 구현: 원본/참고 두 사진 기반 눈·코·입술·턱·눈썹 5부위 이미지 Warp, 전체/부위 강도, 원본/참고/보정 3면 비교, 소스 전환 무효화, 원본 외곽 보호.
- 자동 수학 회귀: 0% 항등, 동일 얼굴 항등, 배경 불변, 최대 변위, 정점 뒤집힘 방지.
- 미검증: 실제 GPU, 측면/가림 얼굴, 3면 확대 동기화, Android/iOS 성능 및 전문 상담 정확성.
- 상담 모드는 v0.3.1 연구 예정이며 실제 성형 결과 예측으로 표시하지 않음.
