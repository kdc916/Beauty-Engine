# maxVFX Beauty Engine — 공식 로드맵 v1.1 (2026-11-04)

> **개발 상태: 앱 v0.1.5 유지. 이 문서는 계획·설계만 개정한 문서이며 Reference Match / Surgery Preview가 구현되었다는 뜻이 아님.**
> 프로젝트: https://github.com/kdc916/Beauty-Engine

## 0. 개발 기준
- 목표: Android, iOS, Windows, macOS에서 공통 프리셋을 사용하는 실시간 뷰티 엔진.
- 기존 베이스: WebGL2 + MediaPipe Face Landmarker + Canvas 2D 폴백, 모바일 고정 프리뷰/독립 컨트롤 스크롤.
- 모든 기능은 코드 반영과 모바일/PC 실기기 QA 완료를 별도로 기록한다.
- 사진 인식 기반 가상 외형 시각화와 실제 임상 수술 결과 예측은 **기술적으로 구분**한다. 후자에 대한 검증 없이 예측·정확도·의학적 보장을 표현하지 않는다.
- 기존 버전 숫자와 로드맵 마일스톤 숫자를 구분한다. `v0.1.5`는 MVP 패치이며 `v0.2` 마일스톤 완료를 의미하지 않는다.

## 2. 기능 우선순위
- **P0:** 이미지 2장 분석, 얼굴 각도·표정 게이트, 안면 해부학적 부위별 정규화 특징값, 안전한 국소 Warp, 0% 원본 보장, 3면 비교 UI.
- **P1:** 피부·메이크업 스타일만 따로 참조, A/B 저장, 다중 참조사진, 추적 시간 안정화 및 회전 대응.
- **P2:** 3D 근사 상담 시각화, 코·턱 세부 형상 표현, 상담 레퍼런스 보드, PDF 보고서 등.
- **하지 않는 것(현재):** '실제 수술 후 얼굴 자동 예측' 정확도 표기, 의학적 진단, 특정 연예인 얼굴을 자동 제공·무단 배포, 사용자 얼굴 원본의 서버 전송/영구보관.

## 3. 필수 통과 게이트
1. **v0.1 → v0.2:** 주요 Android/PC 브라우저에서 현재 필터의 카메라·비교·저장·샘플이 정상 동작.
2. **v0.2.0 → v0.2.1:** Face mesh Warp 영역 제한과 배경 불변 회귀 검사 통과.
3. **v0.2.1 → v0.2.2:** 1인 얼굴·각도·표정·사진 오류 처리 및 두 이미지의 landmark normalization 검증.
4. **v0.2.2 → v0.3.1:** 슬라이더/얼굴 특징의 외형 일치, 사용자 원본 특성 유지, 시각화 고지·내보내기 기록 통과.
5. **v0.3.1 → 출시:** 검증되지 않은 수술 결과 정확도 표시 금지. 의료기관용 사용에는 별도의 법률/규제 및 임상 타당성 검토가 필요.
